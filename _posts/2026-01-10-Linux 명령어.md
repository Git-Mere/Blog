### (명령어) --help
  - 명령어에서 쓸 수 있는 플래그랑 여러 옵션같은 거 보여줌
  - 근데 이거는 간략한 설명 버전, 자주 쓰이는 것들 위주로 보여줌.
  - ex) ls --help
  - 검색하고 싶으면 이렇게 ex) ls --help | grep (검색어)

### grep (문자열)
  - 텍스트에서 특정 문자열이 들어간 줄만 찾아서 출력해줌
  - -i : 대소문자 무시
  - -n : 줄 번호 표시
  - -v : 패턴 제외
  - -r : 디렉토리 재귀 검색

### man (명령어)
  - 그 명령어의 상세한 메뉴얼을 보여줌.
  - ex) man ls
  - ex) man man
- 메뉴얼에는 8가지 항목이 있다. 그리고 내가 찾고자 하는 항목이 그 8가지를 다 가질 수도 있다. 그래서 아래처럼 상세하게 검색가능함.
  - ex) man 1 printf (shell command에 있는 printf 설명)
  - ex) man 3 printf (프로그래밍할 떄 사용하는 printf 함수 설명)
- 메뉴얼 안에서 또 검색을 하고 싶을 때는
  - ex) /(검색어) 이렇게 검색 가능하고 

### apropos (검색어)
  - 명령어 찾을 떄 쓰는 거
  - ex) apropos directory (이러면 메뉴얼 내용에 directory가 포함된 모든 명령어가 나옴.)
  - ex) apropos -s 1,8 director(이러면 man 1, 8했을 때만 나오는 걸 기준으로 검색됨)
  - 만약 apropos를 했는데 (명령어): nothing appropriate. 이렇게 뜬다면 sudo mandb로 db를 업데이트 해줘야 함.

### Tab 두번 누르기 하면 그 명령어 뒤에 올 것들 보여줌. (근데 다 보여주지는 않으니 조심.)

### > 
- 표준 출력(stdout)을 파일로 리다이렉션 하는 연산자
- ex) ls > a.txt 하면 ls로 나오는 것이 a.txt 파일로 저장됨.
  - 여기서 a.txt가 있었으면 내용 삭제하고 덮어쓰기
  - a.txt가 없었으면 파일 생성

### touch
- 파일이 없으면 생성, 있으면 시간만 갱신
- ex) touch file.txt

### pwd
- print working directory
- 현재 워킹 디렉토리를 보여줌. (워킹 디렉토리는 현재 내가 들어가있는 디렉토리를 뜻함.)

### cd
- change directory
- 워킹 디렉토리 변경
- '/' : root directory로 이동
- '-' : 전 디렉토리로 이동
- 아무 플래그, 목적지 없는 cd : home directory로 감.

### mkdir
- 폴더 만들기

### cp [source] [destination]
- 파일, 폴더를 복사
- ex) cp hi.text ../CS261/ (파일)
- ex) cp -r Hi/ ../CS261/ (폴더는 -r 플래그까지)
- -p : 모든 모드, 오너쉽, 시간 까지 모두 복사

### mv [source] [destination]
- 파일, 폴더를 이동 or rename
- 지금 디렉토리 안에 있는 것이면 rename해줌.

### rm
- 파일, 폴더 삭제
- '-r' 폴더 삭제

### 단축키
- Ctrl + U : 커서 앞에 있는 내용 전부 삭제
- Ctrl + K : 커서 뒤에 있는 내용 전부 삭제
- Ctrl + W : 커서 앞 한 단어 삭제
- Ctrl + C : 아예 취소하고 새 줄
### 커서이동
- Ctrl + A : 줄 맨 앞으로
- Ctrl + E : 줄 맨 뒤로
- Ctrl + B : 단어 뒤로
- Ctrl + F : 단어 앞으로

- 그 파일, 폴더의 상세 설명
