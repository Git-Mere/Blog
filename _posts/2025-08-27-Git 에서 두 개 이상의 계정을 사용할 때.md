## Git 2개 이상의 계정을 사용하고자 할 때
*내가 공부한 것이 틀릴 가능성도 있음.. 틀린것이 있으면 댓글로 알려주세요.*

작년 쯤, 기존에 학교에서 과제용으로 사용하던 github계정이 내 포트폴리오 용으로 사용하기에는 너무 더러운 거 같아서 새로운 계정을 하나 팠다. 기존 계정을 A, 새로 만든 계정을 B라고 하면 A의 레포지토리를 B로 옮겼다. 그 떄는 바보같이 하나하나 A의 레포지토리를 clone하고 그 내용을 복사한 뒤에, B에서 새 레포지토리를 만들고 그 안에 복사한 파일들을 업로드했다. 뭐 어찌저찌 모든 레포지토리를 옮기고 하나 수정할 것이 있어서 **git clone https~~~** 명령어를 사용해서 클론하고 커밋하고 푸쉬를 하였다. 근데 푸쉬할 때에 문제가 발생했다. 내가 권한이 없다는 것이었다. 처음에는 이해가 되지 않았다. 깃허브에도 B계정으로 로그인 되어 있었으니까.. 하지만 구글링과 AI의 도움으로 그 원인을 알 수 있었다.

깃허브에서도 볼 수 있듯이  
![select](https://github.com/Git-Mere/Blog/blob/categories-ver2/assets/images/posts_img/git_two_account/1.png)  
이런식으로 우리가 클론할 수 있는 방법이 3개가 있다. 나는 https를 이용하여 clone하는것을 배웠고 주로 해왔다. 하지만 여기서 함정이 있다. https방식으로 clone을 하면 연결되는 계정이 credential manager(Window 자격증명 관리자)에 등록되어 있는 계정으로 연결된다는 것이다. 나도 확인해보니 기존 A계정으로 설정되어 있었다. 그래서 https방식으로 clone한 뒤에, B계정의 레포지토리에 푸쉬할려고 하면 권한이 없다고 거정되는 것이었다.

자 이를 해결하기 위해서는 우선 우리는 ssh를 사용하여야 한다. (credential manager에서 계정을 바꿔서 할 수도 있지만, 번거롭기도 하고 ssh사용 방법도 익힐겸 ssh를 사용하는 것이 더 나은 거 같다.)

## SSH 키 만들기

1. 우선 첫 번째로 key를 생성해야 한다.  

```plaintext
ssh-keygen -t rsa -b 4096 -C "A계정_이메일" -f ~/.ssh/id_rsa_A

ssh-keygen -t rsa -b 4096 -C "B계정_이메일" -f ~/.ssh/id_rsa_B
```

여기서 각 플래그들을 설명한다면  

```plaintext
  - -t rsa는 생성할 키의 타입을 결정
  - -b 4096은 키의 비트 수
  - -C "A계정_이메일"은 이 키의 주석
  - -f 은 이 key가 저장될 위치
```

2. 키가 정상적으로 생성이 됐다면 다음은 각 깃허브 계정의 settings으로 들어가 SSH and GPG keys탭으로 들어간다.  
![setting](https://github.com/Git-Mere/Blog/blob/categories-ver2/assets/images/posts_img/git_two_account/2.png)  
이 화면이 보일 것이다. 여기서 방금 만든 rsa키를 입력을 하면 된다. 파일을 열 수 없습니다. 라는 문구가 뜬다면 오른쪽 마우스를 눌러 메모장으로 편집 버튼을 누르면 그 내용을 확인할 수 있을 것이다. 이 key를 넣으면 된다.

3. 다음 key가 만들어진 .ssh폴더에서 config 파일을 만든다.

```plaintext
# 계정 A
Host (A 호스트 이름)
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_rsa_A

# 계정 B
Host (B 호스트 이름)
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_rsa_B
```

여기서 Host 네임은 아무렇게나 정해도 된다.

4. 잘 됐나 테스트해본다.

```plaintext
ssh -T git@(A 호스트 이름)

ssh -T git@(B 호스트 이름)
# Hi Git-Mere! You've successfully authenticated...
```

성공적으로 됐다면 "Hi (A 호스트 이름)! You've successfully authenticated..."라고 뜰 것이다.

## SSH를 이용하여 clone

여기까지 잘 따라왔다면 ssh key를 만드는 것을 끝난 것이다.
이제 ssh를 이용하여 clone을 하면 된다.

```plaintext
git clone git@(A 호스트 이름):(A계정 username)/(레포지토리 이름).git
```

이런식으로 clone한다면 정상적으로 레포지토리와 내가 원하는 계정과 연결된 상태로 clone이 된다!
