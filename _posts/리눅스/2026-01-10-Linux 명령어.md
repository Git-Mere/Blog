### (명령어) --help
  - 명령어에서 쓸 수 있는 플래그랑 여러 옵션같은 거 보여줌
  - 근데 이거는 간략한 설명 버전, 자주 쓰이는 것들 위주로 보여줌.
  - ex) ls --help
  - 검색하고 싶으면 이렇게 ex) ls --help | grep (검색어)

### grep (문자열)
  - 텍스트에서 특정 문자열이 들어간 줄만 찾아서 출력해줌
  - -i : 대소문자 무시
  - -n : 줄 번호 표시
  - -v : 패턴 제외
  - -r : 디렉토리 재귀 검색

### man (명령어)
  - 그 명령어의 상세한 메뉴얼을 보여줌.
  - ex) man ls
  - ex) man man
- 메뉴얼에는 8가지 항목이 있다. 그리고 내가 찾고자 하는 항목이 그 8가지를 다 가질 수도 있다. 그래서 아래처럼 상세하게 검색가능함.
  - ex) man 1 printf (shell command에 있는 printf 설명)
  - ex) man 3 printf (프로그래밍할 떄 사용하는 printf 함수 설명)
- 메뉴얼 안에서 또 검색을 하고 싶을 때는
  - ex) /(검색어) 이렇게 검색 가능하고 

### apropos (검색어)
  - 명령어 찾을 떄 쓰는 거
  - ex) apropos directory (이러면 메뉴얼 내용에 directory가 포함된 모든 명령어가 나옴.)
  - ex) apropos -s 1,8 director(이러면 man 1, 8했을 때만 나오는 걸 기준으로 검색됨)
  - 만약 apropos를 했는데 (명령어): nothing appropriate. 이렇게 뜬다면 sudo mandb로 db를 업데이트 해줘야 함.

### Tab 두번 누르기 하면 그 명령어 뒤에 올 것들 보여줌. (근데 다 보여주지는 않으니 조심.)

### > 
- 표준 출력(stdout)을 파일로 리다이렉션 하는 연산자
- ex) ls > a.txt 하면 ls로 나오는 것이 a.txt 파일로 저장됨.
  - 여기서 a.txt가 있었으면 내용 삭제하고 덮어쓰기
  - a.txt가 없었으면 파일 생성

### touch
- 파일이 없으면 생성, 있으면 시간만 갱신
- ex) touch file.txt

### pwd
- print working directory
- 현재 워킹 디렉토리를 보여줌. (워킹 디렉토리는 현재 내가 들어가있는 디렉토리를 뜻함.)

### cd
- change directory
- 워킹 디렉토리 변경
- '/' : root directory로 이동
- '-' : 전 디렉토리로 이동
- 아무 플래그, 목적지 없는 cd : home directory로 감.

### mkdir
- 폴더 만들기

### cp [source] [destination]
- 파일, 폴더를 복사
- ex) cp hi.text ../CS261/ (파일)
- ex) cp -r Hi/ ../CS261/ (폴더는 -r 플래그까지)
- -p : 모든 모드, 오너쉽, 시간 까지 모두 복사

### mv [source] [destination]
- 파일, 폴더를 이동 or rename
- 지금 디렉토리 안에 있는 것이면 rename해줌.

### rm
- 파일, 폴더 삭제
- '-r' 폴더 삭제

### 단축키
- Ctrl + U : 커서 앞에 있는 내용 전부 삭제
- Ctrl + K : 커서 뒤에 있는 내용 전부 삭제
- Ctrl + W : 커서 앞 한 단어 삭제
- Ctrl + C : 아예 취소하고 새 줄
### 커서이동
- Ctrl + A : 줄 맨 앞으로
- Ctrl + E : 줄 맨 뒤로
- Ctrl + B : 단어 뒤로
- Ctrl + F : 단어 앞으로

### stat (파일, 폴더 이름)
- 그 파일, 폴더의 상세 설명

### find (경로) 
- -name (입력 인자-이름, 패턴) : 그 파일 패턴과 같은 모든 파일을 찾음. 
  - ex) find CS330 -name '*.jpg' 하면 저 경로의 모든 jpg 파일이 나옴. 
  - ex) find CS330 -iname lab //case sensitive 상관없이 검색
- -size (크기) : 그 크기보다 크거나 작은 모든 파일을 찾음.
  - ex) find CS330 -size +1k //1kb보다 큰 파일을 찾음.
  - c(bytes), k(kb), M(Megabytes), G(Gigabytes)
- -mmin (시간) : 저 시간안에 변경된 파일을 찾음.
  - ex) find CS330 -mmin 5 //정확히 5분 전에 수정
  - ex) find CS330 -mmin -5 //5분 이내에 수정
  - ex) find CS330 -mmin +5 //5분 보다 오래전에 수정
  - mtime 도 있는데 이거는 하루 기준임.
- -perm (권한 숫자)
  - ex) find CS330 -perm 664 //664권한이 있는 모든 파일 탐색
  - '/' : 설정한 숫자 하나라도 설정되어 있으면 탐색
  - '-' : 설정한 숫자 하나라도 포함하여 탐색
- -type
  - f(file), d(directory), l(symbolic link)
- 여러 추가 기호
  - find -name "f*" -size 512k // AND operator
  - find -name "f*" -o -size 512k // OR operator
  - find -not -name "f*" // NOT operator

### cat [file]
- 파일 내용을 위 -> 아래 순으로 그대로 출력
- ex) cat file.txt
- -n : 모든 줄에 번호
- -b : 빈 줄 제외하고 번호

### tail [file]
- 파일의 마지막 부분을 보여줌
- ex) tail text.txt //기본적으로 뒤의 10줄 보여줌.
- -n (숫자) : 숫자만큼 줄을 보여줌.

### head [file]
- 파일의 앞 부분을 보여줌.
- ex) head text.txt //기본적으로 앞의 10줄 보여줌.
- -n (숫자) : 숫자만큼 줄을 보여줌.

### sed [commands] [file]
- 스트림 편집기 (입력을 수정해 보여줄 뿐, 원본 파일은 안 바꿈)
- 줄 단위로 실행됨.
- 치환
  - ex) sed 's/old/new/' file.txt //첫 번째 매칭만 변경해서 보여줌.
  - ex) sed 's/old/new/g' file.txt //해당 줄의 모든 매칭 변경
- 삭제
  - ex) sed '1,5d' file.txt //1 ~ 5 줄 삭제 
  - ex) sed '/error/d' file.txt //error가 포함된 줄 삭제
- -i - 파일을 실제로 수정하고 싶을 때
  - ex) sed -i 's/old/new/' file.txt

### cut [options] [file]
- 각 줄에서 특정 열(field)만 잘라서 출력하는 명령어(구조가 단순한 텍스트에서 열 추출용.)
- 구분자 기준으로 필드 선택 - 구분자는 그 단어들을 뭘로 나눴는지 기준. 즉 Hi:my:name:is:Sam이 있으면 ':'가 구분자가 됨.
- -d : 구분자 지정
- -f : 필드 선택
- -c : 문자 위치 기준
```plaintext
hi,seattle,usa,1234
gogo,seoul,Korea,9332
hs,otawa,canada,866
we,Bali,India,231
```
만약 나라 이름만 추출하고 싶으면 
ex) cut -d ',' -f 3 text.txt

### uniq [file]
- 인접한 중복 줄을 제거하는 명령 - sort랑 같이 쓰는게 국룰
- ex)
```plaintext
usa
canada
usa
usa
canada
```
이렇게 있으면 아웃풋이
```plaintext
usa
canada
usa
canada
```
이렇게 나옴. 
그래서 정석은 sort file.txt | uniq 이런 식으로 사용.

### diff [option] [file] [file2]
- 두 파일의 차이점을 비교해서 보여줌.
- 만약 둘이 완전히 동일하면 아무것도 안 나옴.
```plaintext
3c3
< apple
---
> banana
```
출력이 이런 식으로 나옴.
- 3c3 : 첫 번쨰 파일의 3번째 줄이 두 번쨰 파일의 3번쨰 줄로 변경
- < : 첫 번째 파일 내용
- \> : 두 번째 파일 내용
변경 타입 기호
- a : 추가
- d : 삭제
- c : 변경

자주 쓰는 옵션
- -u : 자세하게 잘 보임. ㅋㅋ
- -y : 좌우로 나란히 비교
- -c : 자세하게 보여줌.

### more [file]
- 긴 텍스트 보기 편하게 해주는 뷰어(?) 명령어
- 앞으로만 이동
- space : 다음 페이지
- enter : 한 줄씩

### less [file]
- 긴 텍스트 보기 편하게 해주는 뷰어 명령어(more 상위호환)
- 양방향 이동 가능
- 검색 가능
- -i : 이거 입력하고 검색하면 case sensitive 토글을 껏다켰다 할 수 있다.

### vim [file]
- 텍스트 에디터
- 모드 기반
  - Normal : 이동, 삭제, 복사
  - Insert : 실제 입력
  - Visual : 영역 선택
  - Command : 명령 실행
- 기본 실행 종료
  - :wq : 저장 후 종료
  - :q : 종료
  - :q! : 강제 종료
  - :w : 저장
- 파일 다루기
  - :e [file] : 다른 파일 열기
  - :ls : 버퍼 목록
- 삭제/복사/붙여넣기(Insert 모드)
  - x : 문자 삭제
  - dd : cut
  - yy : copy(줄 단위)
  - p : paste
  - u : undo
