### git 모든 브런치 보기
  git branch -a

### 로컬 변경사항 전부 버리기
  git restore .

### 스테이징 올리기
  git add (파일이름)

### 스테이징 버리기
#### 스테이징 : 커밋 <-> 스테이징 <-> 로컬 (즉 어떤 것을 커밋할지 선별해서 올려두는 공간)
  git reset --hard

### Git이 추적 중인 .orig파일 전부 삭제
  git rm -f "**/*.orig"

### Git 추적 안 된 .orig까지 전부 삭제
  git clean -f "**/*.orig"

### Git 추적 안 된 .orig까지 전부 탐색
  git clean -n "**/*.orig"
